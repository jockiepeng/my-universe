以前尝试新工具，总想找到一个能解决所有问题的系统。后来发现，真正留下来的，往往只是几个很小、很顺手的习惯。

## 先看重复发生的问题

如果每天都要找同一个文件、复制同一段文字，或者反复整理相似的资料，这些才是值得优化的地方。先记下阻力，再决定要不要增加一个工具。

> 好的工具不需要一直提醒我它的存在，它只是让事情更顺利地发生。

## 让工具待在顺手的位置

把常用的操作留给几个记得住的快捷键，把临时想法放进一个固定的收集入口。比起复杂配置，容易开始更重要。

| 想解决的问题 | 一个简单的做法 |
| --- | --- |
| 临时想法容易丢失 | 固定一个文字收集入口 |
| 文件总是找不到 | 使用清晰的日期和主题命名 |
| 每次都重复相同操作 | 把重复动作整理为模板 |

一个 Markdown 记录可以从这样的结构开始：

```markdown
# 今天想记下的事

## 发生了什么

## 我想到了什么

## 下次可以试试什么
```

## 定期做一次减法

偶尔看看那些已经很久没有打开的工具。卸下多余的选择，让真正好用的部分留下来。

这份清单会继续变化，判断标准也很简单：它有没有让我少折腾一点。
