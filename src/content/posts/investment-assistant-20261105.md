今天大A一片喜气洋洋，但最近 A 股和美股的行情都不太理想，账户亏损严重，活脱脱一棵韭菜。行情不好是一方面，自己也存在不少问题：投资认知不足、研究不够深入，最重要的是没有严格执行交易纪律。

这段时间一直在学习投资知识，看课程、读研报、做笔记、问 AI，确实有些收获，但总感觉效率不高。笔记零散，想用的时候不好找；关注的公司需要持续跟踪，信息收集又很耗时间；真正到了买卖的时候，之前制定的交易纪律反而容易被抛在脑后。

前几天重新用起了 AI，很快就搭建好了自己的个人博客。突然想到，既然 AI 已经这么强大了，为什么不利用它来搭建一套属于自己的投资系统呢？

目前的构思是这样：

1. 建立投资知识库
使用 GitHub 创建一个投资仓库，统一管理代码、投资纪律、研究笔记和研报分析。通过 VS Code 和 Codex CLI 调用 ChatGPT，辅助整理学习内容，提炼关键结论，并记录数据来源，逐渐积累自己的投资知识库。

2. 建立交易决策辅助系统
每次准备买卖股票时，让 AI 结合最新行情、持仓情况和自己制定的交易纪律，逐项检查投资逻辑是否成立、价格是否合理、风险能否承受，避免一时冲动就下单。

3. 建立公司跟踪系统
针对自己关注的上市公司，设置定时任务，自动收集最新公告、财报和重大事件，分析这些变化是否影响原有的投资判断。

4. 搭建可视化网站
最后再做一个网页，把投资笔记、公司研究、持仓情况、交易纪律等集中展示，方便随时查看和复盘。
