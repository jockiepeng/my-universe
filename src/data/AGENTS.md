# 功能更新记录

编辑 `changelog.json` 时遵循仓库 README 的“功能更新记录规则”。新增记录须提供中英文摘要和可展开的 `details`（每项含 `title`、`enTitle`、`text`、`en`）。新增功能说明功能内容和技术原理；修复及优化说明原来的情况、处理方式、更新后的效果和技术原理。删除记录说明内容、原因和影响，适用时说明原理。以实际实现为依据，历史条目无需补写。

功能更新只记录网站功能、修复、优化及功能删除；普通文章和贴图的发布、编辑、迁移不记入更新列表，也不要求补写功能更新记录。清理历史内容发布条目不另增更新条目；内容发布仍须审查隐私、图片、列表入口和构建结果。
