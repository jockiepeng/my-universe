# 求一支签

入口：首页「求一支签」、工具页，地址 `/tools/fortune/`。

## 求签流程

页面在签筒前常驻展示四步说明：先静心，在心里想好一件具体的事；选择观音签或车公签并点击“求一支签”；等竹签落定后点击“展开签纸”（也可跳过动画）；对照心事阅读签诗与本站白话解读，想想下一步能做什么。问题不用输入或说出口，也可以不带问题。

本站采用简化体验，不要求焚香、填写生辰或掷筊；说明仅针对本站操作，不作为各地庙宇仪式的统一规则。

## 签文与版本

观音签 100 支，车公签 96 支。展开签纸后，直接显示签号、传统签级、四句签诗及对应的本站白话解读；无须跳转或请求外部服务。完整签库在 `src/data/fortune-texts.json`。

当前采用传统通行本，编号、诗句和分级按易安居的[观音签目录](https://www.zhouyi.cc/lingqian/guanyin/)及[车公签目录](https://www.zhouyi.cc/lingqian/chegong/)逐页核对。每支签都保留 `sourceUrl`，签纸底部可查阅对应的整理页。只整理传统签诗及编号、等级，不收录来源站现代长篇评注、图像、设计或疾病、投资等事项的预测。每条白话解读均为本站另行撰写，以诗中意象提供自省角度，明确标注「本站白话解读」。

各庙签本存在字词、签级与顺序差异；页面标明「传统通行本」。此版本不再使用华人庙宇委员会的现代修订本，也不宣称为某寺庙的官方版本。源页的异体字和异文保留，不凭现代解读擅改古诗。示例核对：观音第 1 签「开天辟地作良缘」、第 100 签「佛神灵通与君知」；车公第 1 签「帅灵地杰逞英豪」、第 96 签「山水相逢淘沙金」。本版来源核对及解读整理于 2026-11-05。

首版只抽签号并链接委员会官网；本版按用户要求补全站内阅读。历史只存签种、号码与时间，因此旧记录仍保留这些原始信息，阅读时按当前通行本显示，不冒充抽取时保存过的签诗快照。

## 行为与维护

- 选择签种，点击求签，约 2.2 秒后出签，再点击展开签纸；可跳过动画，再求一签。
- 每个签筒内每支签等概率。Web Crypto uint32 拒绝采样避免简单取模的余数偏差，不按签的吉凶调概率，也没有每日次数限制。
- 以 `little-universe-fortunes-v1` 在本机 localStorage 保存最近 20 次签种、签号、抽取时间。界面统一显示北京时间。刷新恢复最近结果，切换签种恢复各自最近的签。
- 不收集所问之事，不跨设备同步。存储不可用时仍可抽签和阅签，并提示刷新可能丢失。损坏或越界的记录被过滤。
- 系统减少动态效果或网站关闭动态时，点击后直接出签；键盘可操作全部按钮。禁用 JavaScript 时提供签诗来源目录。
- 签文随本站脚本交付；外链仅供查阅出处。文本通过 DOM 文本节点渲染，历史数据不能注入签文或任意外部 URL。

`fortune.mjs` 管理抽样、签文查找与历史；`fortune.ts` 管理状态和签纸文本；`FortuneTube.astro` 为原创 SVG；`fortune.css` 管理主题及动画。更新签库时，保持两套编号连续、每签四句、解读非空且逐签对应，并同步来源与版本说明。

验证：`npm run verify`；构建后 `npm run test:fortune`。单元测试遍历全部 196 支签；浏览器检查签诗、等级、解读与来源一致，首尾签、刷新及历史恢复、320px 布局、禁用存储和动画。浏览器测试阻止外站请求，验证站内阅签不依赖来源站。截图在 `.tools/screenshots/fortune-*.png`。
