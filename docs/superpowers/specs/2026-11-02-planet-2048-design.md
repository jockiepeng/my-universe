# 2048 星球合成

## 已确认的规则
用户选择经典 2048：4×4 棋盘，方向键或手机滑动控制整盘；相同数字相碰合并，每块每回合只能合并一次。有效移动生成一个 2 或 4，无效移动不生成。合成 2048 获胜并可继续，满盘且无相邻同值方块时结束。

## 实现选择
- 在现有 Astro 游戏大厅加入 `/games/2048/`，不新增依赖或后端。
- 保留数字，给每一级配星体名称和 CSS 绘制的星球。视觉主题不是天体演化的科学模拟。
- 当前分数为所有合并结果的累加；保留最高分、步数和当前棋盘，刷新继续。
- 新方块按经典概率生成：2 为 90%，4 为 10%，空位等概率。
- 新游戏使用确认对话框，保留最高分。
- 棋盘内支持触屏滑动，外部正常滚动；另有可点击方向按钮。
- 减少动态或关闭动态时取消棋盘动画。禁用存储仍可玩，显示无法保存提示。
- 胜利提示与结束提示显示在棋盘之外，不能遮住棋盘；胜利有继续按钮。

## Approaches
选择现有栈的 DOM/CSS 棋盘与独立纯函数规则模块。Canvas 会增加文字可访问性和点击测试成本；额外游戏框架对此规模无益。沿用现有游戏页外壳，不改博客首屏开场代码。

## 视觉
沿用博客正文字体。棋盘深蓝 `#122a40`，格位 `#203c54`，描边 `#476079`，星光金 `#f0cd88`，浅蓝 `#c4e1ee`，星体青 `#78c8be`。分数和规则左对齐，格内数字居中。

桌面：左侧大棋盘、右侧星体图鉴和规则；手机单列，棋盘最大 480px、最小适配 320px 视口。蓝金色棋盘是唯一主要视觉，避免重复装饰卡片。

```text
游戏大厅 / 标题与简介
分数  最高分  步数       新游戏
┌───────────────┐  当前最高星体
│  4 × 4 星球棋盘 │  星体图鉴
└───────────────┘  游戏规则
```

## 验收
合并方向与只合并一次有单元测试；无效移动不生成、胜利继续、满盘可合并、存档损坏有覆盖。真实浏览器验证大厅入口、键盘、触屏、刷新恢复、重开确认、胜负提示、320px 无横向溢出、深浅色与减少动态。
