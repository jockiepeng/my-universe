# 提交与推送 Review 门禁

用户已选择仓库规范 + Git hooks，并批准开始编码。根 AGENTS.md 约束助手，pre-commit / pre-push 检查代码快照对应的报告。报告保存于 docs/reviews，绑定父提交与排除顶层 JSON/Markdown 报告后的 Git 树指纹，避免循环哈希。报告必须覆盖隐私、功能专区、内容列表、Bug 和实际验证证据。

红线：敏感信息、未解决缺陷、必要验证失败或未完成、发布内容不可见或资源损坏、草稿泄露、功能说明缺失/空泛/与代码不符、过期或缺少报告。新增/修复/优化/删除说明遵循 README 的双语详情要求。语义和图片隐私由审查者确认，自动化验证结构和快照，不能证明无所有 Bug。

方案比较：仅 AGENTS.md 不拦手动 Git；增加本地 hooks 可拦普通提交和推送，采用此方案。远程 CI/分支保护不在本次范围。本地机制不是防恶意篡改的安全边界。

用户追加：最终输出 Markdown 校验文档，开头标注审查范围、结果和重点关注事项，下面展开具体证据；门禁要求 JSON 与 Markdown 同步。
