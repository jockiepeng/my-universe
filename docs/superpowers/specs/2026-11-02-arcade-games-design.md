# 四款小游戏扩展

用户已选择星际贪吃蛇、扫雷、打砖块、连连看，接入既有游戏大厅。沿用 Astro + 原生 TypeScript，无新运行时依赖、账户或后端。

## 结构与选择

四款独立路由 `/games/snake/`、`/games/minesweeper/`、`/games/breakout/`、`/games/link/`。各自纯逻辑 `.mjs`、DOM 控制 `.ts`、页面和必要样式分离；共用 ArcadeLayout 与 arcade.css。大厅以六款真实游戏呈现，不使用假按钮。比分记录保存当前浏览器，失败时提示并继续玩。

曾考虑引入游戏框架，但四款规则简单，原生 Canvas 与 DOM 更适合现有静态站，避免增加加载体积。实时游戏采用 Canvas，扫雷和连连看采用可聚焦的 DOM 格子，键盘和触屏各有明确控制。

## 规则

- 星际贪吃蛇：20×20 网格，三档速度；吃星星加 10 分，随机食物仅放空格，撞墙或身体结束，不能反向，允许移动到本步移开的尾巴；满盘获胜。方向键/WASD、滑动及四向按钮；开始/暂停/继续、重开、最高分；后台自动暂停。
- 扫雷：简单 9×9/10 雷、中等 12×12/22 雷、困难 16×16/40 雷。首次翻开时生成雷区，首格与周围一圈安全；空白区域自动展开，数字提示八邻雷数，全部非雷格翻开即赢。右键或手机模式切换插旗；方向键移动、Enter/Space 操作、F 插旗。计时从首翻开始，暂停计时不暴露棋盘，分难度保存最快纪录。窄屏困难棋盘在容器内滚动，页面无横向溢出。
- 打砖块：挡板反弹球，清完砖块过关、关卡速度渐增；3 条生命，失球扣命，结束后可重开。鼠标/触摸/方向键与屏幕按钮控制；开始/发球、暂停/继续；每块 10 分。物理步进防高速穿透，反弹角由落点决定；后台自动暂停；保存最高分。
- 连连看：相同图案用不超过两次转弯的水平/垂直线连接，中间不能穿过未消除格子，可走棋盘外围。简单/普通棋盘，限时；选中后可取消、错配提示、不扣错配分。提示与洗牌有次数限制；洗牌保留剩余图案并保证存在可消对，没有合法连接时自动处理而不死锁。计时与棋盘在暂停时冻结并遮盖。保存最高分，重开清当前局。点选或键盘选格；显示连接轨迹。

## 视觉与交互

沿用站点 Segoe UI/PingFang SC/Microsoft YaHei，外层主题变量；深蓝桌面 #122b43、夜空 #081b2d、星光白 #edf5ff，贪吃蛇用青绿 #8edcc0，扫雷用金 #efcc8a，砖块用珊瑚 #ed9685，连连看用天蓝 #9ac6f1。主要可玩画面左侧、操作/规则右侧，手机上下排列。比分用数字对齐；装饰只出现在游戏预览与棋盘。尊重减少动态设置，动效跟随操作，不做无关自动动画。

## 验证边界

各纯逻辑使用 Node 测试：碰撞、边界、胜负、首击安全、连线路径/死局、砖块反弹与失命。真实浏览器检查六个入口、四款操作、暂停/后台冻结、重开、存储失败、320/390px 深浅主题、可访问键盘控制及零脚本错误。保留现有骰子、2048、阅读量说明和首屏修复。
