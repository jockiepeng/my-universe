# 游戏大厅与三骰猜大小

用户希望从首页进入可扩展的游戏大厅，先实现三骰猜大小，可以持续下注、设置金币、查看历史和最常出现的点数，并重新开始。

## 实现选择

沿用 Astro 静态页面与原生 TypeScript，无新增依赖。前端虚拟金币和 localStorage 适合现有 GitHub Pages；账户后端与跨设备同步增加服务器成本，本轮不采用。首页按钮与主导航进入 `/games/`，大厅只有一个真实可玩的游戏 `/games/dice/`，后续通过游戏目录添加项目。

## 玩法与边界

- 当前采用的默认解释：指定数字指总点数，最高出现的点数指频次最高的总点数。这两项已向用户异步询问，未回答时按推荐解释实现。
- 三颗公平六面骰；小为 4–10，大为 11–17；三颗相同为豹子，大小下注都输。历史同时标记豹子和其点数对应的大小。
- 大小净赔率 1:1；总点数 4/17 为 50:1、5/16 为 18:1、6/15 为 14:1、7/14 为 12:1、8/13 为 8:1、9/10/11/12 为 6:1。总点数下注遇到豹子仍按总和结算。3/18 记录但不可下注。
- 一局可同时下注多个位置，选择筹码后点击位置累计下注，清空按钮撤回本局全部待下注。有效金币为正整数，初始金币默认 1,000，可设 1–1,000,000；单次筹码同范围。结算不得产生负数或不安全整数。
- 开骰后立即保存完整结算，再播放短动画；动画期间禁止重复操作，刷新不会撤销已结算回合。金币、初始金币及全部历史自动保存本机，存储失败时当前页面仍可玩并提示。
- 显示回合数、胜局数、净盈亏、最常出现点数及并列、3–18 点分布。历史每次显示 20 条，可继续加载。重新开始需要确认、按指定金币创建新局，全部历史与统计清空。
- 余额为零可重新开始；输入无效、余额不足不扣款。坏存档恢复默认且提示；多标签页旧页面操作前拒绝覆盖新进度并同步。

## 界面

沿用网站字体 Segoe UI / PingFang SC / Microsoft YaHei 和主题变量。桌面主区为骰桌与下注，侧栏为历史，下方是分布与规则；手机按操作、统计、历史排列。骰桌用海军蓝 #183952、深蓝 #102b42、白骰 #fffdf5、金色 #f0cd88、红点 #be433b；外围沿用网站主题。骰子点阵与筹码是主要视觉记忆，不增加独立的花哨背景。支持键盘、状态播报、无脚本说明、减少动态和 320px 宽屏幕。
