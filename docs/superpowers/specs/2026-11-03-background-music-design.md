# 博客背景音乐

用户已选定 Moonlight、Hiraeth、Dream Culture，并要求下载后用于博客背景音乐。沿用已提出的默认关闭、手动播放、暂停、切歌与音量控制方案。

采用本地 MP3 与原生 HTMLAudioElement，不依赖外站播放器或额外运行库。全站左下角放紧凑的音乐入口，展开后选择三首曲目、播放或暂停、前后切歌、调整音量与进度。继承博客现有字体和场景颜色，手机宽度 320px 可用，首页开场期间隐藏入口，不参与搜索索引。

首次访问不设置音频 src，不发出音频请求。音量默认 20%。记住曲目、时间和音量；本标签页用户明确开启后，跨页可以尝试恢复播放，浏览器阻止时提示手动点击，不承诺无缝播放。暂停后不会因切页或切歌自行恢复声音。存储受限仍可正常操作。请求失败时显示可理解的错误，支持重试或切歌；播放到末尾顺序循环三首。

三首从作者官方 MP3 地址下载至 public/audio，保留原始音频。播放器提供可见的作者、原曲链接、CC BY 4.0 链接。public/audio/credits.txt 与 docs/background-music.md 记录下载地址、校验值和来源说明。用途是博客内容的伴奏，不提供独立音乐下载站、流媒体再发行或 Content ID 注册。

现有 scripts/browser-smoke.mjs 和 src/styles/global.css 有另一个窗口的未提交修改。本次在当前工作区增加独立组件、脚本和样式，只在 BaseLayout 挂载组件，避免重写这些共享文件；不自动提交推送本功能。

验收覆盖：无初始音频请求、三首实际解码与播放、暂停切歌、末尾循环、音量与进度、跨页恢复、自动播放被拒绝、音频失败后的恢复、存储禁用、键盘、窄屏与开场遮罩。
