# 首页访客信息

用户已确认：首页展示当前访客自己的 IP 归属地，以及累计访问次数；不需要访客人数或后台访客明细。

- 用户修订：归属地用定位图标加地名呈现，不显示「你来自」；统计文案采用「累计浏览量」，表示全站页面浏览次数（PV），重复打开或刷新可能增加。
- 在《我的个人博客是如何搭建的》补充两项功能的请求、数据来源、显示、失败处理和统计口径等实现原理。
- 首页主介绍下方加入紧凑信息区（右侧栏在手机上隐藏），沿用字体、颜色、分隔线；手机自然换行。不展示原始 IP，不申请设备精确定位。
- 所有正式页面只加载一次不蒜子，首页展示 site_pv，文章继续展示 page_pv。只在配置的 HTTPS 正式来源启用，开发与本地预览不发送真实请求。
- IP 归属地由支持 HTTPS、浏览器跨域、无需密钥的公开接口提供，只在首页查询。查询超时、限流、缺失字段或网络错误时显示「暂不可用」；用 textContent 显示响应，拒绝异常数据。
- 不伪造或推算浏览量，不用本地累计数。超时显示占位和明确提示，允许统计迟到响应恢复。

## 方案比较

复用现有不蒜子并调用公开归属地接口：适合现有 Astro + GitHub Pages，无需服务器或新依赖，采用此方案。自建 API、数据库与统计后台需要独立托管和运维，超出当前展示需求。归属地仅反映出口 IP 的大致区域，代理可能改变结果；公开接口的配额和可用性属于外部依赖。

## 实现者决定

展示位置、接口选型和失败提示由实现者确定并验证。第三方累计记录按其站点识别规则归属，不保证项目子路径与同一主机的其他站点隔离；新增接入不会补齐从未计数的历史访问。
