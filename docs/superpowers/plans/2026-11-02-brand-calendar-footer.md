# 站名、固定页脚和日历 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution. 用户已要求直接修改现有网站，本次不重复确认已指定的功能。

**Goal:** 将站名统一为“jockie的小宇宙”，固定头部与页脚，并增加当前日期、月历和实时时钟。

**Architecture:** 保留 Astro 静态输出，日历通过浏览器时钟在上海时区计算，每秒刷新时间、跨日更新日期与月历。页脚独立于布局容器固定在视口底部，正文预留其实际高度，避免遮挡。

**Spec:** 当前用户的三项修改与后续纠正：站名为 `jockie的小宇宙`。

## Design decisions

- 页脚按“固定”字面实现为常驻视口底部；短页面与滚动长文都保持底部位置，正文仍能完整滚动到末尾。
- 日历桌面放首页侧栏；手机移到文章列表上方，日期和时钟常显，月历默认折叠。
- 使用北京时间（Asia/Shanghai、24 小时制、显示秒），不请求外部时间服务。
- 当前日期高亮，周一为每周第一天；跨日、跨月、跨年刷新；隐藏页面暂停计时，重新可见立即校准。
- 延续现有深空/沙滩与深浅色配色，不引入依赖。关闭脚本时明确提示实时日历需启用脚本，不冒充构建日期为今天。

## Validation focus

- 月份首日为周日、二月闰年、上海时间跨日与跨年。
- `container-type` 会改变 fixed 元素的包含块，页脚必须置于该容器之外。
- 页脚折行、移动端安全区、禁用 JavaScript 时正文底部仍有足够空间。
- 每秒更新时间不使用 aria-live，避免不断打断读屏；月历不承诺日程或文章日期筛选。
