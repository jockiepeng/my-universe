# 单行导航修订

用户要求固定导航不分两行，定位与博客累计浏览量放在右侧。将 VisitorInfo 直接放入主导航行并使用 order:4，取消独立信息行；桌面增加导航可用宽度，地区过长省略显示，完整文字仍在 DOM 中。1000px 以下将导航与原操作按钮放入可展开菜单，定位和浏览量保留右侧；菜单支持外侧点击、Escape 和导航后关闭。无脚本时保留可访问的导航回退。

验证：同一水平中心线、右侧位置、手机固定栏高度、菜单开关、320px 溢出、日历/搜索/场景原交互。当前另一个窗口在同一 Header 文件添加工具入口，保留其工作区修改，提交时仅纳入本次布局改动。

复核发现并复现横屏日历裁切：弹层改为相对固定栏定位，按实际起点限制高度；无脚本窄屏回退为正常文档流，避免折行遮挡正文。菜单收起同时关闭子弹层，搜索对话框的 Escape 保留给搜索自身处理。
