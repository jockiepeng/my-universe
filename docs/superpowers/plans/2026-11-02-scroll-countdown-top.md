# 滚动修复、2027 倒计时与返回顶部

用户要求修复无法上下滚动，增加距 2027 年和 2027 农历新年的倒计时，以及文章右侧返回顶部箭头。

## 已定位的问题

真实 Chrome 滚轮诊断：主页、正文和右侧目录上滚动均不生效，scrollY 为 0，body 的 computed overflow 为 clip。原型遗留的 `.universe { overflow:clip }` 传播至页面滚动区域；之前程序 scrollTo 检查未覆盖实际滚轮输入。

另需移除短目录上的 overscroll containment，避免鼠标位于右侧目录时阻断正文滚动。

## 实现

- [ ] 移除整页纵向 clip，保留横向约束；用真实滚轮验证正文、首页、右侧目录与头尾固定栏。
- [ ] 倒计时使用北京时间，目标分别为 `2027-01-01T00:00:00+08:00` 与 `2027-02-06T00:00:00+08:00`。
- [ ] 目标日期依据：[香港政府 2027 年公众假期公告](https://www.info.gov.hk/gia/general/202605/15/P2026051400300.htm)。
- [ ] 与日历时钟共用每秒更新；到期不出现负数，不自动切换到 2028 年，显示已到达。
- [ ] 文章右侧提供返回顶部箭头，滚动后显示，固定在页脚上方；保留原生锚点与减少动态效果支持。
- [ ] 完整测试、构建、浏览器交互与视觉检查；本轮仍为本地开发，不自动发布。
