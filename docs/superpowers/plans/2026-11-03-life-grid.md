# 人生格子 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增工具区与人生格子，支持出生日期、预计寿命和日／周自由切换，以格子墙呈现人生进度。

**Architecture:** 纯函数模块处理公历日期、日周分组及格子明细。Astro 页面提供语义化表单、统计与键盘查询，Canvas 控制器负责密集绘图、一次性揭示和缩放。

**Tech Stack:** 现有 Astro 7、TypeScript、Canvas 2D、Node test runner、Playwright；不新增依赖。

**Spec:** `docs/superpowers/specs/2026-11-03-life-in-days-design.md`

## Global Constraints

- 一格一天或从出生起连续七天；寿命 1–120 整岁，默认 80；计算包含闰日。
- 今天按访客本地日期；完成数不含今天；周完成数只计完整周，最终不足七天的格子在终点后完成。
- 不保存、上传或将输入写入 URL；兼容基础路径、手机、主题、关闭动态与无 JS 提示。
- 不自动提交、推送或发布；仅交付当前工作区可审查的改动。

## Review Focus

- DST 和时区：通过日历字符串转整数日，跨夏令时不多／少一天；纯函数测试。
- 终点为闰日与最后不足一周：末格边界准确、到终点剩余为零；纯函数测试。
- 视图切换和快速提交：同一模型、旧动画取消、详情和查询上限同步；浏览器测试。
- 缩放后空白格／边距：点击不映射到错误格子、放大仅图内滚动；浏览器验证。
- 运行中主题、动态及日期改变：重新绘制并刷新模型；浏览器测试主题和动态，检查日期更新逻辑。
